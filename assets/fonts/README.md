# Public Sans

The interface bundles the Latin subset of Public Sans as a variable WOFF2 font (weights 100–900), distributed under the [SIL Open Font License 1.1](OFL.txt).

- Project: [USWDS Public Sans](https://github.com/uswds/public-sans)
- License source: [Google Fonts, Public Sans](https://github.com/google/fonts/blob/main/ofl/publicsans/OFL.txt)
- Font source: [Google Fonts CDN, Public Sans v21](https://fonts.gstatic.com/s/publicsans/v21/ijwRs572Xtc6ZYQws9YVwnNGfJ7QwOk1.woff2)
- Downloaded: 2026-11-09
- SHA-256: `c1b6da516e0062e9c2f341b3a51dd2d621d946da72f06c6cfe05fd9d2dd8622d`

The build embeds the font as a data URL and includes the license text in `index.html`. There are no runtime font downloads. System sans-serif fonts provide glyphs absent from the Latin subset, including some scientific symbols.
